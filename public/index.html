Integration flow

What happens after submission?

  1. The browser converts the form fields into JSON.
  2. The JSON is sent to the Node.js API.
  3. The API validates and normalizes the data.
  4. The email is matched to an institutional person.
  5. The registration and vehicle are saved in a transaction.
  6. The API returns a structured response.
